    One key connects everything.

    Your connection key gives the widget activity updates and bot controls. There is no separate management key.

    Paste it once into the widget's Connect panel.

    1. Import the botRanch widget into iCUE.
    2. Allow 127.0.0.1:43822 in iCUE Settings > Software Settings > Widget Access.
    3. Open Connect in the widget and paste this key.
