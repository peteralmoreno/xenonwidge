Native OMP command helper

Managed OMP /loop tasks are unavailable: OMP 18.8.6 does not expose safe extension command delivery and final-loop events for Ranch. This helper only copies a command for a separate, standalone OMP terminal. It cannot save or run a managed loop task.

Use for repeated reasoning, fixing or verification. Every iteration may use model tokens. A duration is a repetition budget, not a polling interval. For external job progress checks, use Pipeline monitoring.

The first iteration runs before the condition is checked. Conditions use shell exit status. Choose a verification command, not a deployment or job submission. Reaching a limit does not prove success.

Paste into a separate OMP terminal, not PowerShell or an active Ranch task. While enabled, /loop disables repetition; interrupt suspends it. See docs/guides/bot-ranch-loop.md for usage and context modes.
