# Widget sources

Keep each widget's editable files in its own folder here, for example `sources/doodle-pad/`.

A widget folder contains its manifest, HTML, scripts, styles, icons, and other bundled resources. Make changes here, then validate and package the widget.

Run the [source build](../docs/guides/build-and-import.md) to generate widget and companion packages under artifacts/releases. Research links remain in [documentation references](../docs/reference/sources.md).

Projects: [Doodle Pad](doodle-pad/README.md), [Audio Deck](audio-deck/README.md), and [Bot Ranch](omp-bot/README.md).
